# v1.7.1

## Added

- `skills/documentation-sync/SKILL.md`: new `## Follow-ups` section documenting the `docs/FOLLOWUPS.md` convention. Covers the per-entry template (h1 title, `Commit range`, `Branch name`, `Added on`, `## Follow-up Items`, `## Additional Notes`), inclusion/exclusion rules (code-only deferred work; no user-acceptance items), entry lifecycle (prepend on new work; annotate completed items in-place via `~~strikethrough~~ (completed YYYY-MM-DD)` rather than deleting; do not rotate on version cuts — file is a standing log spanning versions), and a recommended `[Any-Code-Change]` Documentation Sync entry for projects adopting the pattern.
- `CLAUDE.md`: added `docs/FOLLOWUPS.md [Any-Code-Change]` entry to the `## Documentation Sync` section so the project itself adopts the new pattern.
- `docs/FOLLOWUPS.md`: initial empty standing log with a header note describing the prepend-and-annotate convention.
- `skills/documentation-sync/docs/setup.md`: new `### Create Tracked Files (and Folders) That Don't Yet Exist` step in the setup flow. Explicitly directs the agent to create both the parent directories (`docs/release-notes/`, `docs/changelogs/`) and the `upcoming.md` files inside them, plus (when the project opts into the Follow-ups pattern) `docs/FOLLOWUPS.md` with its standard header. Other listed files (guides, CLI docs) are left to the user unless they explicitly ask for a stub.

## Changed

- `skills/documentation-sync/SKILL.md` `### Choosing the Bump`: replaced the strict-SemVer table with a pragmatic, size-of-change framing. `patch` is now the default for routine work (including small features and refactors); `minor` covers medium-sized change sets and may include scoped reverse-incompatible changes; `major` is reserved for extremely large change sets, sweeping rewrites, broad reverse-incompatible work, or dropped support — still gated on explicit user instruction. Added a closing line noting that an isolated breaking change inside an otherwise medium-sized set fits a `minor`, while a broad pattern of breaking changes is a `major`.
