# v1.6.0

- feat(commands): new `/broker-mode` slash command runs a canonical
  read-execute-respond loop, one iteration per inbox batch.
- feat(broker): `broker recv` returns a single batch of messages and exits;
  `--timeout` controls max wait for the first message and `--burst-window`
  (default 5s) controls the post-first-arrival drain window.
- feat(skill): broker skill rewritten around Broker Mode as the canonical
  pattern; Monitor-streaming and standalone wait-for-reply recipes removed.
- breaking: `broker follow` is removed; use `broker recv` instead.
- breaking: `--idle-timeout` is removed; use `--timeout` + `--burst-window`.
- breaking: presence is scoped to an in-flight `broker recv`; Broker Mode
  agents appear `offline` between iterations.
