# v1.8.3

- Added a contradiction-detection rule to the capabilities-SDLC skill. Before completing a code change that affects user-facing behavior, agents now check whether the change conflicts with any existing `capabilities.md` entry by status, scope, or listed conditions. Conflicts are surfaced to the user with a question — update the capability file to match the new behavior, or revise the change to fit the existing entry. Capability files are never silently rewritten on the user's behalf.
