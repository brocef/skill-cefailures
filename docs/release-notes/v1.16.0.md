# Upcoming

- Removed the `broker`, `elkjs`, `ieee`, `knex`, `openai-api`, and `typebox` skills, along with the message broker CLI and its slash commands. The plugin now ships `brain-style`, `capabilities-sdlc`, `documentation-sync`, and `report`.
- The `CLAUDE.md` style command is now `/skill-cefailures:brain-style:agents-md`. It reviews (or authors) a project's `AGENTS.md` as the canonical agent-instructions file, checks that `CLAUDE.md` (and other agents' entrypoints) symlink to it, and stresses keeping the file to bare essentials — with task-specific instructions routed to their own files, a length ceiling, nested files for large repos, and a no-secrets rule.
