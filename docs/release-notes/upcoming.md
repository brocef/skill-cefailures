# Upcoming

## New skills

- **`capabilities-sdlc`** — Conventions for documenting user-facing capabilities of Proposit applications in markdown files co-located with the code. Defines the file format, three-status taxonomy (`Supported` / `Missing` / `Omitted`), the planning-gate rule (every spec/plan/briefing for user-facing work opens with a `## Capability changes` section), and the broker-mediated protocol for cross-repo product-layer coordination. Includes four fully-written exemplars (server user route, server API endpoint, mobile feature folder, mobile screen component).
