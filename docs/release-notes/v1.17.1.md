# v1.17.1

## Added

- **The plugin now carries a license.** skill-cefailures is Apache-2.0, with a `LICENSE` file at the repo root and the license declared in both the Claude and Codex plugin manifests. Nothing about it declared a license before.

## Fixed

- **The marketplace can now be added from the claude.ai web app and the Claude Desktop plugin directory.** Both previously failed with "Marketplace sync failed. Check the repository URL and try again." Two defects were found and fixed: the repo contained a symlink that pointed at its own parent, so the plugin folder contained itself without end, and the marketplace listing was missing its description, owner email, and plugin author. Confirmed working against the published repo on 2026-08-11.

  Installing from the command line was never affected, and still works exactly as before.

  Both fixes shipped together, so which one the sync had actually been objecting to is not known.
