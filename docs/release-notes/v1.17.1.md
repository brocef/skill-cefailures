# v1.17.1

## Added

- **The plugin now carries a license.** skill-cefailures is Apache-2.0, with a `LICENSE` file at the repo root and the license declared in both the Claude and Codex plugin manifests. Nothing about it declared a license before.

## Fixed

- **Packaging fixes aimed at adding the marketplace from the claude.ai web app and the Claude Desktop plugin directory.** Both previously failed with "Marketplace sync failed. Check the repository URL and try again." Two defects were found and fixed: the repo contained a symlink that pointed at its own parent, so the plugin folder contained itself without end, and the marketplace listing was missing its description, owner email, and plugin author.

  Installing from the command line was never affected, and still works exactly as before.

  This has not yet been confirmed against the web app — the same two fixes made the sibling TCW plugin syncable, but the sync happens on Anthropic's servers and can only be checked once these changes are published. If it still fails, the error message will look identical, because that one message covers every possible rejection.
