# Upcoming

## New

- **`/skill-cefailures:process-inbox`** — a new slash command that turns `docs/inbox/` into a drop zone for pre-written task prompts. Drop a `.md` or `.txt` file (or a folder bundling a request doc with supporting artifacts) into `docs/inbox/`, then run the command and an agent will pick it up, read it, route it through your installed skills (superpowers if available), and move the source into `docs/inbox/.archive/` once it's been ingested. Folder bundles are useful when a request needs to ship with images, SVGs, sample data, or any other accompanying files.
