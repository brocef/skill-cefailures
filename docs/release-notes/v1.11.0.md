# v1.11.0

## New orchestrator command: `process-inbox-initiative`

A new slash command, `/skill-cefailures:process-inbox-initiative`, codifies the
multi-repo initiative workflow the workspace-root orchestrator used to paste by hand
into every inbox request document. It builds on `process-inbox` (reusing its inbox
handling) and then drives the full recipe: mark capabilities first, write an overview
spec and seed the initiatives ledger, spawn researchers and an architect to plan and
spec the work, dual-review each spec with a human final check, implement in parallel
worktrees, and integrate per repo.

The command is orchestrator-only by design — it is a command rather than a skill so it
never loads into per-repo agent contexts. Per-repo agents continue to use
`process-inbox`.
