# ieee

IEEE style for writing/editing IEEE-compliant text and for building software that models IEEE citation types. Based on the Reference Style Guide, Editorial Style Manual, and Mathematics Style Guide for Authors.

| Doc | Scope |
|-----|-------|
| `docs/reference-types-academic.md` | Conferences, periodicals, theses/dissertations, reports, lectures, courses, unpublished works |
| `docs/reference-types-media.md` | Books, blogs, websites, online videos, software, datasets, news articles |
| `docs/reference-types-formal.md` | Patents, standards, handbooks, manuals, legal citations, government documents |
| `docs/reference-schemas.md` | TypeBox schema patterns, field taxonomy, validation rules, rendering to IEEE string |
| `docs/citing-rules.md` | In-text citation syntax, abbreviation rules, DOI/URL placement, author name formatting |
| `docs/editorial-style.md` | Article structure, writing conventions, grammar/usage, acronyms, inclusive language, special paper types |
| `docs/math-style.md` | Equation formatting, break/alignment, italic vs roman, numbered equations, symbols/functions |
