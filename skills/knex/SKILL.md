# knex

Node.js SQL query builder for configuring connections, running migrations, building schema, and generating SQL across multiple database clients.

| Doc | Scope |
|-----|-------|
| `docs/installation.md` | Install Knex core + DB drivers + migration CLI |
| `docs/initialization-and-clients.md` | Initialize Knex with different clients; connection strings, SSL, custom clients |
| `docs/advanced-configuration.md` | Migrations, pooling, dynamic connections, user params, response hooks, debugging |
| `docs/query-builder-sql-examples.md` | Dialect SQL output for returning, joins, CTEs, unions, except, count, where raw |
| `docs/schema-builder-sql-examples.md` | Schema builder SQL: timestamps, nullability, foreign keys, unique constraints/indexes |
| `docs/troubleshooting.md` | Common Knex setup pitfalls and debugging tactics |
